# Security & Privacy Policy

## 🔒 Privacy & Architecture Commitment

ConvertsText is engineered as a **100% Client-Side Web Application**:
- All text processing, case conversion, phonetic audio playback, regex filtering, and readability scoring happen entirely within the user's browser runtime.
- No user-inputted text is ever sent to any remote servers, cloud databases, or third-party tracking APIs.
- We operate under a strict **Zero-Database Pledge**.

---

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability (e.g., XSS vector, header misconfiguration, or client sanitization bypass), please report it responsibly:

1. **Email**: Open a security advisory on GitHub or email the maintainer directly at `security@convertstext.com` or `tehzeeb.mts.9@gmail.com`.
2. **Details to include**:
   - Description of the issue
   - Step-by-step reproduction steps or proof-of-concept payload
   - Impact assessment
3. **Response Time**: We will acknowledge receipt within 48 hours and work on a prompt resolution.

Thank you for keeping ConvertsText and its users safe!
